# **App Name**: AbanTechnologies Enterprise Portal

## Core Features:

- Tri-Phase Theme System: A sophisticated environment switcher allowing users to toggle between Midnight Cyber, Arctic Glass, and Neon Matrix aesthetics with seamless Framer Motion transitions.
- AI Solution Architect: A generative AI chatbot that acts as a tool to analyze business requirements, recommend technical stacks, and assist in booking consultations.
- Secure Project Nexus: An enterprise-grade client dashboard for tracking project development, managing support tickets, and secure document exchange.
- Global Tech Commerce: A comprehensive billing and booking engine integrating local African mobile money (MTN, Airtel) with international gateways like Stripe and PayPal.
- Enterprise Case-Study Vault: A high-performance interactive portfolio showcasing complex systems such as DEVS and Hospital management with dynamic filtering.
- Admin Operational Hub: A centralized platform for managing client relationships, project lifecycles, and site analytics with an enterprise-level interface.
- Cyber-Grid Hero Interface: A premium landing experience featuring interactive particle backgrounds, glowing gradients, and scroll-triggered animations inspired by cybersecurity platforms.
- Unified Ecosystem Trust Blocks: Dedicated UI components for professional social proof, animated performance statistics, and security-first engineering showcases.

## Style Guidelines:

- Theme-dependent palettes: Midnight Navy (#0f1629) with Neon Blue for cyber focus, Silver/White with frosted glass for luxury, and Black with Neon Green for hacker aesthetics.
- Use of 'Space Grotesk' for futuristic, tech-oriented headlines and 'Inter' for high-density, professional body text to ensure maximum clarity.
- Custom thin-line SVG icons featuring dynamic outer glows and animated paths that react to user interaction.
- Enterprise-grade spacing with generous padding, strict grid alignment, and glassmorphism panels inspired by premium cybersecurity platforms like HackerOne.
- Sophisticated use of Framer Motion for scroll-triggered reveals, floating 3D hover effects, and persistent background particle systems to simulate an active AI environment.
